Como foi criado o site do JD · Estudo de referência

O jdandrade.art é o portfólio do João Daniel Andrade, artista e escritor. Este estudo preserva o relato original de criação com Claude Code e Higgsfield; o projeto não é apresentado como trabalho de Gabriel Holanda ou da Norte Autoral.

Os prompts abaixo foram preservados como escritos pelo criador original, incluindo erros de digitação. As obras da galeria são do JD, feitas à mão por ele.

Passo 1

Desenhe o site antes de pedir o site

Em vez de descrever o site em palavras, o criador original gerou uma imagem de como ele ficaria, com as cores e o estilo de arte do JD. Ele usou o Higgsfield com o GPT Image, o modelo de imagem do ChatGPT, e anexou quatro referências: um fundo de gradiente com granulado, duas artes do JD e um site de outro estúdio como referência de layout. O JD gostou da imagem antes de existir uma linha de código.

Prompt da imagem · Higgsfield · GPT Image
High-fidelity desktop portfolio website comp, 1440x900. Panoramic stage website: compact nav above one uninterrupted horizontal illustrated procession. Oversized JD ANDRADE typography recedes behind three scene windows like cinema frames; foreground silhouettes cross frame edges; a lit storybook aperture labeled LIVROS anchors the right, ARTE anchors the left. Red-orange-deep-blue grain fills the canvas, bold editorial rhythm, kinetic but highly legible. Show start of next project strip. Real text only: JD ANDRADE, ARTISTA + ESCRITOR, ARTE, LIVROS; greek all other text.
(anexei 4 imagens: o gradiente com granulado, uma pintura do JD, uma ficha de personagem do JD e o site de referência)
Por que funcionaUma imagem fecha cor, fonte, ordem das seções e clima de uma vez. A IA que vai programar não precisa adivinhar o que você imaginou.
Repare no fim do promptSó o texto real vai escrito (JD ANDRADE, ARTISTA + ESCRITOR, ARTE, LIVROS). O resto pede "greek", que é texto de mentira. Assim a imagem não inventa palavra errada no meio do layout.

Passo 5

Um painel pra ele atualizar sozinho

Para que o próprio JD pudesse atualizar obras e informações, o criador solicitou um painel com acesso protegido. O pedido abaixo faz parte do relato original:

O pedido do painel
Queria que pegasse automaticamente os posts do artstation, mas se fosse dar muito trabalho e nao ficasse igual esse, deixa quieto, vamos fazer uma aba com login e senha protegidos para que ele possa publicar os posts/artes e editar as informaçoes do site, artes em destaque, adicionar livros, editar etc, alterar fotos
Conferindo
a aba de projetos é customizavel pelo painel de adm?
resposta: sim, com a lista do que dava pra editar
Com print
Na aba admin e projetos, permita o ajuste da posiçao da imagem de abertura, para nao cortar igual o exemplo acima
Página de links
https://linktr.ee/jdandradeart ele tem um linktree, vamos fazer uma aba de links, onde ele pode editar pelo painel de ADM
Português e inglês
faça uma versão em ingles tbm, garanta que os textos possam ser escritos tanto em ptbr quanto em ingles na pagina de admin
Uma recomendação do relato originalA IA cria uma senha provisória pro painel. Troque por uma sua logo no primeiro dia, e nunca mande essa senha num print.
Passo 6

Colocar no ar

Três mensagens. A Vercel é onde o site fica hospedado; o GitHub guarda cada versão do código.

Publicar
manda pro vercel, usando o MCP e me mande o link
Atualizar sozinho
faz o vercel conectar nesse github, que ai quando commita o github o vercel atualiza
Domínio
ele comprou um dominio no namechap, mande uma mensagem pra eu copiar e colar mandando pra ele configurar o dns

Com os dois conectados, quando o JD salva alguma coisa no painel, aquilo vira uma versão nova no GitHub e o site se atualiza sozinho. Essa é a rotina de atualização descrita no relato original.
